# 🧠 Quiz Application

A responsive quiz app built with HTML, CSS, and JavaScript featuring multiple-choice questions, a countdown timer, and real-time score tracking.

## 🚀 Features

* Multiple-choice questions
* Countdown timer
* Instant answer feedback
* Final score display
* Restart functionality

## 🛠️ Tech Stack

HTML • CSS • JavaScript

## 📂 Structure

index.html • styles.css • script.js
